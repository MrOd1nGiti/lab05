# Лабораторная работа 5. Обработка строк

Выполнил: Вариант 1

## Описание программ

- `normalize.py` - удаляет лишние пробелы в начале, конце и внутри строки, выводит исходную/новую длину и количество слов.
- `palindrome.py` - проверяет строку на палиндром с игнорированием регистра и пробелов.
- `replace.py` - подсчитывает количество двоеточий и заменяет их на дефисы.
- `variant.py` - вариант 1: выделяет слова из текста, очищает их от знаков препинания по краям, приводить к нижнему регистру и отбирает те, которые начинаются на букву "а".

## Проверка работы программ

### normalize.py
- Ввод: `"  Один   два  "`
  Вывод:
  Исходная длина: 14
  Новая длина: 8
  Нормализованный текст: Один два
  Количество слов: 2
- Ввод: `""`
  Вывод:
  Исходная длина: 0
  Новая длина: 0
  Нормализованный текст: 
  Количество слов: 0

### palindrome.py
- Ввод: `"А роза упала на лапу Азора"`
  Вывод: Палиндром
- Ввод: `"а    "`
  Вывод: Палиндром
- Ввод: `"   "`
  Вывод: Нет текста
- Ввод: `"Python"`
  Вывод: Не палиндром
- Ввод: `"А!"`
  Вывод: Не палиндром

### replace.py
- Ввод: `"a::b:"`
  Вывод:
  Количество замен: 3
  Новая строка: a--b-
- Ввод: `"abc"`
  Вывод:
  Количество замен: 0
  Новая строка: abc

### variant.py (Вариант 1)
- Ввод: `"Анна, армия! Я читаю. Книга, край, рама."`
  Вывод:
  анна
  армия
  Всего слов: 2
- Ввод: `"!!!"`
  Вывод:
  Нет совпадений
  Количество: 0
- Ввод: `""`
  Вывод:
  Нет совпадений
  Количество: 0

## Ответы на вопросы к защите

1. **Неизменяемость строк в Python**: Строки (`str`) являются неизменяемым типом данных (immutable). Любые методы строк (например, `strip()`, `replace()`, `lower()`) не меняют исходную строку в памяти, а возвращают новый объект строки.
2. **Отличие слова от подстроки**: Слово в данном контексте — это обособленный элемент текста, полученный при разделении строки по пробельным символам (и очищенный от пунктуации). Подстрока — это любая непрерывная последовательность символов внутри строки (например, `"ан"` является подстрокой для слова `"анна"`).
3. **Задание правил обработки пунктуации до написания кода**: Символы пунктуации могут искажать результаты операций (например, при проверке на палиндром или поиске слов по первому/последнему символу). Если не определить заранее, удаляются ли знаки препинания и на каком этапе, это приведет к неверным результатам анализа текста.
